# 线性代数：矩阵特征值对应特征向量（真题高频）

## 核心结论

若 $A\alpha=\lambda\alpha$，则特征值、特征向量随矩阵运算的对应关系如下表：

| 矩阵 | 特征值 | 对应特征向量 |
|---|---|---|
| $A$ | $\lambda$ | $\alpha$ |
| $kA$ | $k\lambda$ | $\alpha$ |
| $A^{-1}$ | $\dfrac{1}{\lambda}$（$\lambda\neq0$） | $\alpha$ |
| $A^*$ | $\dfrac{|A|}{\lambda}$（$\lambda\neq0$） | $\alpha$ |
| $A^m$ | $\lambda^m$ | $\alpha$ |
| $f(A)$ | $f(\lambda)$ | $\alpha$ |
| $A+kE$ | $\lambda+k$ | $\alpha$ |
| $A^T$ | $\lambda$ | 特征向量一般不同，不能直接沿用 $\alpha$ |
| $B=P^{-1}AP$（与 $A$ 相似） | $\lambda$ | $P^{-1}\alpha$ |
| $B+2E$（$B$ 与 $A$ 相似时） | $\lambda+2$ | 对应 $B$ 的变换后特征向量 |

## 补充结论

- 若 $B=P^{-1}AP$（$A$ 与 $B$ 相似），则 $A$ 与 $B$ 的特征值完全相同（含重数）；特征向量按 $P$ 做基变换换算，不能直接照搬。
- 伴随矩阵用 $A^*=|A|A^{-1}$（$A$ 可逆时）。

## 高频例题链

1. 由 $A$ 的特征值求 $A^*$ 的特征值：先用 $A^*=|A|A^{-1}$。
2. $B=P^{-1}A^*P$ 与 $A^*$ 相似，特征值相同。
3. 求 $B+2E$ 时，各特征值再加 2。
4. $B$ 的特征向量按 $P$ 的基变换关系由 $A^*$ 的特征向量转换得到。

## 易错点

- 先确认 $A$ 可逆，再使用 $A^*=|A|A^{-1}$。
- 相似变换下特征值可直接沿用，但特征向量不能直接照搬原矩阵的特征向量。
- 矩阵函数作用在特征向量上时，特征值同步取函数值：$f(A)\alpha=f(\lambda)\alpha$。
