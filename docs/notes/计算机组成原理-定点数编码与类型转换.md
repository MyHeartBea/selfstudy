> 本文按王道《计算机组成原理》主线整理，并补充 C 语言类型转换、字节序、符号/零扩展等考研高频考点。

## 0. 前置概念

### 0.1 真值与机器数

- 真值：带正负号的真实数值，如 $+5$、$-5$。
- 机器数：真值在机器中的编码，符号位也参与存储，如 $5$ 的原码 $0\;0101$、$-5$ 的原码 $1\;0101$。
- 机器字长 $n$：一个机器数占 $n$ 位，通常最高位为符号位，其余 $n-1$ 位为数值位。
- 定点数：小数点位置固定不变。按小数点位置分为：
  - 定点整数：小数点固定在数值位最低位之后；
  - 定点小数：小数点固定在符号位之后、最高数值位之前。

### 0.2 常用英文对照

| 中文 | 英文 |
| --- | --- |
| 原码 | sign-magnitude code |
| 反码 | one's complement code |
| 补码 | two's complement code |
| 移码 | biased notation / excess-N code |
| 符号扩展 | sign extension |
| 零扩展 | zero extension |

## 一、定点数编码表示

以下统一讨论“机器字长 $n$ 位，其中 1 位符号位、$n-1$ 位数值位”。

### 1.1 原码

#### 定义

符号位用 0 表示正、1 表示负，数值部分为该数绝对值的二进制形式：

$$
[x]_{\text{原}} =
\begin{cases}
0,\;|x| & x \ge 0 \\
1,\;|x| & x \le 0
\end{cases}
$$

#### 示例

设 $n=5$：

- $+5$：真值 $0101$，原码为 $0\;0101$；
- $-5$：真值绝对值 $0101$，原码为 $1\;0101$；
- $+0$：$0\;0000$；
- $-0$：$1\;0000$。

#### n 位表示范围

定点整数：

$$
-(2^{n-1}-1) \le x \le +(2^{n-1}-1)
$$

定点小数：

$$
-(1-2^{-(n-1)}) \le x \le +(1-2^{-(n-1)})
$$

例如 $n=4$ 的定点整数原码范围为 $-7 \sim +7$，其中 $-0$ 为 $1000$，$+0$ 为 $0000$。

#### 特点

- 与真值最直观，人类容易看出符号和大小。
- 0 有两种表示：$+0$ 和 $-0$。
- 加减法实现复杂：需要判断两数符号是否相同，还要比较绝对值大小，硬件电路复杂。
- 乘除法可把符号位单独处理（同号为正、异号为负），数值位按绝对值相乘除。

### 1.2 反码

#### 定义

正数的反码与原码相同；负数的反码是“原码符号位不变，数值位按位取反”。

设 $x$ 为 $n$ 位定点整数，反码可写成：

$$
[x]_{\text{反}} =
\begin{cases}
x & 0 \le x < 2^{n-1} \\
(2^n-1)+x & -(2^{n-1}-1) \le x < 0
\end{cases}
$$

#### 示例

设 $n=5$：

- $+5$：$0\;0101$；
- $-5$：原码 $1\;0101$，数值位 $0101$ 取反得 $1010$，反码为 $1\;1010$；
- $+0$：$0\;0000$；
- $-0$：$1\;1111$。

#### n 位表示范围

定点整数：

$$
-(2^{n-1}-1) \le x \le +(2^{n-1}-1)
$$

定点小数：

$$
-(1-2^{-(n-1)}) \le x \le +(1-2^{-(n-1)})
$$

#### 特点

- 0 有两种表示：$000\cdots0$ 和 $111\cdots1$。
- 反码不能表示 $-2^{n-1}$。
- 反码做加法时若最高位有进位，需要“循环进位”（把进位加到最低位），运算规则比补码复杂。
- 反码主要用于过渡，例如由原码求补码时，可先“按位取反”得到反码，再末位加 1。

### 1.3 补码

#### 定义

正数的补码与原码相同；负数的补码为“原码符号位不变、数值位按位取反后末位加 1”，等价于“按位取反再加 1”。

设 $x$ 为 $n$ 位定点整数，补码定义：

$$
[x]_{\text{补}} =
\begin{cases}
x & 0 \le x < 2^{n-1} \\
2^n + x & -2^{n-1} \le x < 0
\end{cases}
$$

定点小数的补码模为 2：

$$
[x]_{\text{补}} = 2 + x \qquad (-1 \le x < 0)
$$

#### 快速求法

对负数：写出原码后，**符号位不变**，数值位取反再加 1。

另一种技巧：从最右侧第一个 1 开始，该 1 及其右边所有位不变，左边所有位（含原符号位）全部取反。

#### 示例

设 $n=5$：

- $+5$：$0\;0101$；
- $-5$：原码 $1\;0101$，数值位取反 $1010$，加 1 得 $1011$，补码为 $1\;1011$；
- 用技巧验证：$101$ 的最右 1 是最后一位，右边不变为 $1$，左边 $010$ 取反为 $101$，得到 $1\;1011$。

#### n 位表示范围

定点整数：

$$
-2^{n-1} \le x \le +(2^{n-1}-1)
$$

定点小数：

$$
-1 \le x \le +(1-2^{-(n-1)})
$$

例如 $n=4$：整数范围 $-8 \sim +7$，最小数 $-8$ 的补码为 $1000$；定点小数最小可表示 $-1$（$1.000$），这是原码和反码都做不到的。

#### 补码还原真值

符号位为 0：直接按二进制读出。

符号位为 1：先对补码“取反加 1”得到绝对值，再添负号。

例如 4 位补码 $1101$：取反得 $0010$，加 1 得 $0011=3$，所以真值为 $-3$。

#### 特点

- 0 的补码唯一：$000\cdots0$。$+0$ 与 $-0$ 编码相同。
- 能表示 $-2^{n-1}$，比原码、反码多一个最小负数。
- 加减法统一为加法：$x-y$ 可写成 $x+(-y)$，用 $[x]_{\text{补}}+[-y]_{\text{补}}$ 实现。
- 符号位直接参与运算，最高位产生的进位可自然丢弃，只要不溢出，结果仍正确。
- 求相反数：$[-x]_{\text{补}}$ 等于 $[x]_{\text{补}}$ 按位取反再加 1。

### 1.4 移码

#### 定义

移码是在补码基础上把符号位取反，等价于给真值加一个偏置常数 $2^{n-1}$：

$$
[x]_{\text{移}} = 2^{n-1} + x
$$

其中 $x$ 的范围与补码一致。

#### 示例

设 $n=4$：

| 真值 | 补码 | 移码 |
| --- | --- | --- |
| $-8$ | $1000$ | $0000$ |
| $-1$ | $1111$ | $0111$ |
| $0$ | $0000$ | $1000$ |
| $+7$ | $0111$ | $1111$ |

#### 特点

- 移码的 0 唯一，编码为 $1000\cdots0$。
- 移码大小顺序与真值大小顺序一致：真值越大，移码也越大，因此**适合浮点数阶码的比较**。
- 移码与补码只有符号位不同，数值位完全相同。
- 移码一般用于定点整数（尤其是浮点数的阶码），很少用于定点小数。

### 1.5 四种编码对比表（n 位定点整数）

| 编码 | 表示范围 | 0 的表示 | 主要用途/特点 |
| --- | --- | --- | --- |
| 无符号数 | $0 \sim 2^n-1$ | 唯一 $00\cdots0$ | 地址、无符号运算 |
| 原码 | $-(2^{n-1}-1) \sim +(2^{n-1}-1)$ | $+0$ 和 $-0$ 两种 | 直观，运算复杂 |
| 反码 | $-(2^{n-1}-1) \sim +(2^{n-1}-1)$ | $+0$ 和 $-0$ 两种 | 补码过渡 |
| 补码 | $-2^{n-1} \sim +(2^{n-1}-1)$ | 唯一 $00\cdots0$ | 加减统一，最常用 |
| 移码 | $-2^{n-1} \sim +(2^{n-1}-1)$ | 唯一 $10\cdots0$ | 浮点阶码、大小比较 |

### 1.6 定点小数表示范围表

设 1 位符号位、$n-1$ 位数值位：

| 编码 | 表示范围 |
| --- | --- |
| 原码 | $-(1-2^{-(n-1)}) \le x \le +(1-2^{-(n-1)})$ |
| 反码 | $-(1-2^{-(n-1)}) \le x \le +(1-2^{-(n-1)})$ |
| 补码 | $-1 \le x \le +(1-2^{-(n-1)})$ |

### 1.7 补码运算与溢出

#### 补码加减

加法：$[x+y]_{\text{补}} = [x]_{\text{补}} + [y]_{\text{补}}$。

减法：$[x-y]_{\text{补}} = [x]_{\text{补}} + [-y]_{\text{补}}$，其中 $[-y]_{\text{补}}$ 由 $[y]_{\text{补}}$ 取反加 1 得到。

示例（4 位补码）：

$$
3 + (-2) = 0011 + 1110 = 10001
$$

最高位进位 1 丢弃，结果取低 4 位 $0001 = 1$，正确。

#### 溢出

运算结果超出机器数能表示的范围即为溢出。**只有同号相加（或异号相减）才可能溢出。**

判断方法：

1. 符号位法：两个正数相加结果符号为 1，或两个负数相加结果符号为 0，则溢出。
2. 进位法：最高数值位向符号位的进位与符号位向更高位的进位不同，则溢出。
3. 双符号位（变形补码）：$00$ 表示正、$11$ 表示负、$01$ 表示正溢出、$10$ 表示负溢出。

示例（4 位补码）：

$$
7+1 = 0111 + 0001 = 1000
$$

两个正数相加得到符号位为 1 的 $1000$，按补码读是 $-8$，结果错误，发生正溢出。

### 1.8 移位运算

#### 逻辑移位

- 左移：最高位移出，最低位补 0。
- 右移：最低位移出，最高位补 0。

适用于无符号数，左移相当于乘以 2，右移相当于除以 2（向 0 取整）。

#### 算术移位

- 左移：最低位补 0，可能产生溢出。
- 右移：最高位补**符号位**。

补码的算术右移一位约等于除以 2（向负无穷方向取整）。

示例：4 位补码 $-3 = 1101$，算术右移一位得 $1110 = -2$，而 $-3/2 = -1.5$，向负无穷取整得 $-2$。

#### 循环移位

循环左移/右移：移出的位补到另一端；带进位循环移位还会经过进位标志位。

### 1.9 定点数编码高频考点小结

- n 位无符号数范围：$0 \sim 2^n-1$。
- 原码、反码范围相同，都含 $+0$ 和 $-0$，都不能表示 $-2^{n-1}$。
- 补码范围比原码/反码多一个最小负数，0 唯一。
- 移码范围与补码相同，0 唯一且为 $100\cdots0$。
- 求补码负数：原码数值位取反加 1；补码求相反数：整体取反加 1。
- 补码符号扩展：高位补符号位，数值不变。
- 浮点数阶码常用移码，原因是移码能按无符号大小直接比较。
- 变形补码双符号位 $01$ 正溢出、$10$ 负溢出。

## 二、数据类型转换

### 2.1 C 语言常见整数类型与位数

#### 常见 32 位环境（考研默认场景）

| 类型 | 常见位数 | 有符号范围 | 无符号范围 |
| --- | --- | --- | --- |
| char | 8 | $-128 \sim 127$（若为 signed） | $0 \sim 255$ |
| short | 16 | $-32768 \sim 32767$ | $0 \sim 65535$ |
| int | 32 | $-2^{31} \sim 2^{31}-1$ | $0 \sim 2^{32}-1$ |
| long | 32 | $-2^{31} \sim 2^{31}-1$ | $0 \sim 2^{32}-1$ |
| long long | 64 | $-2^{63} \sim 2^{63}-1$ | $0 \sim 2^{64}-1$ |

#### 64 位环境

- Linux（LP64）：long 为 64 位，其余同上。
- Windows（LLP64）：long 仍为 32 位，long long 为 64 位。

#### C 标准保证

$$
\text{sizeof(char)}=1,\qquad \text{char} \le \text{short} \le \text{int} \le \text{long} \le \text{long long}
$$

C 标准只保证最小位数：char 至少 8 位、short 至少 16 位、int 至少 16 位、long 至少 32 位、long long 至少 64 位，具体由实现决定。

#### 补充

- char 是否有符号由实现决定，x86 上通常为 signed char。
- 指针在 32 位环境占 4 字节、64 位环境占 8 字节。
- `sizeof` 的返回类型是 `size_t`，本质上是无符号整数。

### 2.2 位模式、字节序与存储

- 一个整数在内存中按字节存放，字节序只影响存储顺序，不影响补码位模式本身。
- 小端：低字节存在低地址。$0x12345678$ 存为 $78\;56\;34\;12$。
- 大端：高字节存在低地址。$0x12345678$ 存为 $12\;34\;56\;78$。

类型转换本质上是“对同一段二进制位模式重新解释”，或者“改变位模式长度”。

### 2.3 位截断

#### 规则

宽类型转窄类型时，**保留低位，丢弃高位**。

#### 示例

$$
int\;0x12345678 \xrightarrow{\text{转 short}} short = 0x5678
$$

截断后：

- 无符号解释下，新值等于原值对 $2^n$ 取模；
- 有符号解释下，符号位可能改变，数值可能发生大幅变化。

#### 易错点

- 截断不是四舍五入，而是直接丢掉高位。
- `char c = 300;` 若 char 为 8 位，$300 \bmod 256 = 44$，c 的值为 44。

### 2.4 零扩展

#### 规则

**无符号数**从窄类型转宽类型时，高位补 0。

#### 示例

$$
unsigned\;char\;0x80 = 128 \xrightarrow{\text{零扩展}} int = 0x00000080 = 128
$$

零扩展不改变原数值。

### 2.5 符号扩展

#### 规则

**有符号数**从窄类型转宽类型时，高位补**符号位**：

- 正数（符号位 0）：高位补 0；
- 负数（符号位 1）：高位补 1。

补码的符号扩展不改变真值。

#### 示例

$$
signed\;char\;0x80 = -128 \xrightarrow{\text{符号扩展}} int = 0xFFFFFF80 = -128
$$

$$
4\text{位补码 }1101\ (-3) \xrightarrow{\text{扩展为 8 位}} 11111101\ (-3)
$$

#### 补充：原码、反码的扩展

- 原码扩展：符号位不动，数值位高位补 0。
- 反码扩展：负数高位补 1，保持反码定义。
- 考研最常考补码的符号扩展。

### 2.6 整型提升与隐式转换

#### 整型提升

`char`、`short`（无论 signed 还是 unsigned）参与运算前，先提升为 `int`；若 `int` 不能表示其所有可能值，则提升为 `unsigned int`。

#### 常规算术转换（简化顺序）

$$
int < unsigned\;int < long < unsigned\;long < long\;long < unsigned\;long\;long < float < double
$$

混合运算时向排名高、表示范围更大的类型转换。**同宽度有符号与无符号混合时，有符号数转换为无符号数。**

#### 典型陷阱

例 1：

```c
-1 < 0u
```

`-1` 先转换为 `unsigned int`，变成 $2^{32}-1$，因此表达式为假。

例 2：

```c
unsigned char a = 200, b = 100;
a + b  // 整型提升为 int，结果是 300，不是 unsigned char
```

例 3：`sizeof(arr)` 返回无符号 `size_t`，若写成 `i < sizeof(arr)`，当 `i` 为有符号 int 时会发生有符号转无符号的隐式转换。

### 2.7 强制类型转换

- 显式强制转换分为“等宽重解释”和“改变宽度”两类。
- 同宽度 signed/unsigned 互转：不改变内存位模式，只改变解释方式。
- 窄转宽：有符号按符号扩展，无符号按零扩展。
- 宽转窄：截断高位，保留低位。
- 浮点转整数：向 0 截断，可能溢出或丢失精度。

### 2.8 数据类型转换高频考点

| 场景 | 结果 |
| --- | --- |
| `signed char 0x80` 转 `int` | 符号扩展为 `0xFFFFFF80`，值为 $-128$ |
| `unsigned char 0x80` 转 `int` | 零扩展为 `0x00000080`，值为 128 |
| `int 0x12345678` 转 `short` | 截断为 `0x5678` |
| `-1` 转 `unsigned int` | `0xFFFFFFFF`，即 $2^{32}-1$ |
| `unsigned char 200 + unsigned char 100` | 整型提升为 `int`，结果为 300 |
| 小端存储 `0x12345678` | 内存字节为 `78 56 34 12` |

## 三、自测题

1. 8 位补码能表示的最小整数和最大整数分别是多少？
2. 8 位移码中 0 的编码是多少？
3. `signed char c = 0x80; int i = c;`，i 等于多少？
4. `unsigned char c = 0x80; int i = c;`，i 等于多少？
5. 32 位环境中 `int x = 0x12345678; short s = (short)x;`，s 的十六进制值是多少？
6. 表达式 `-1 < 0u` 在 C 语言中为真还是假？
7. 4 位补码中，$0111 + 0001$ 的结果是否溢出？
8. 小端机器上 `int x = 0x12345678` 从低地址到高地址的字节是什么？

### 答案

1. 最小 $-128$，最大 $+127$。
2. $10000000$。
3. $-128$（符号扩展为 `0xFFFFFF80`）。
4. $128$（零扩展为 `0x00000080`）。
5. `0x5678`。
6. 假（`-1` 转为无符号后为 $2^{32}-1$）。
7. 溢出：两个正数相加得到 `1000`，按补码读为 $-8$。
8. `78 56 34 12`。
